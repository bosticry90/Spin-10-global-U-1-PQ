# Connected source products: the proof obligations

The following is a prospective plan, not a qualified extension theorem.
The existing NSP map defines proper derivatives at fixed mean fields.
At fixed ordinary j, the one-loop Legendre functional is instead
W1=-Gamma1(phi0(j,J),J). Two derivatives give the five terms frozen in
RECORD, with the full second mean derivative. The source2 contribution
S_phi_ij and the tadpole Gamma1_phi[y_ij] must not be omitted.

The old proper trace proof uses independent node momenta with poles<=2
or<=3 for one tangent. Sewing can make a tree momentum equal a difference
of loop node momenta. A simple locally-L1 product argument no longer
suffices. For example, the arrangement q,p,q+p in eight dimensions with
degrees2,2,2 is locally integrable; the total degree6 is below8 and each
proper rank-one subspace has degree2 below4. A single degree increase
still gives7<8. This is a useful minimal configuration, not by itself an
all-graph sewing proof. Actual tree endpoints and branching vertices,
zero-transfer contacts and zero-label tadpoles need separate checks.

Ja's base affine endpoint is an auxiliary Lambda leg. Its source-generated
mean therefore uses the mixed Green entry, with a weaker pole than a
generic vector source. The u endpoint adds the already qualified derivative
B, Lambda and intrinsic scalar channels. Derive their complete adjoint
operators and both endpoint orientations, without borrowing field-tangent
Fourier signs. All other source endpoints retain field/test labels.

For the unlabeled part of y_ij inspect actual S0 cubic vertices, u-source
second derivatives and the u source2 contact. The physical/gauge-fixing
term programs, not a generic gauge argument, determine the outgoing
channel. Every labeled remainder must retain its independent slots in
any subsequent graph proof. Formal constant scalar chains are bounded
reference expansions, not a physical massive-resummation theorem.

An actual scalar tadpole vector T cannot be assigned zero. It may be
annihilated by the projected response or restricted by demonstrated
covariance of the actual action/reference. If a massless inverse still
multiplies its delta at zero momentum, identify the exact required
condition/extension instead. No Schwartz-to-Schwartz inverse or silent
tadpole/vacuum normalization is assumed. Finite counterterm A0/A2 freedom
must stay correlated with the connected prescription.

First obtain and independently test the full finite Legendre identity and
the actual operator/support data. Then assess the analytic bridge. Do not
turn those algebraic successes into an unsupported full connected/QAP
claim. A precise surviving sewing condition is useful scientific progress.
