# SYR1 algebra and scalar bubble

The parity-even crossed-Clifford trace is defined by chi²=1,chiGamma=-Gamma
chi, reduction of all chi to the right, zero for odd chi, and the usual
metric-pairing Gamma trace for even chi. It is a specific restricted trace,
not the physical epsilon trace with a single gamma5. For barred words,
averaging the actual physical chi orientations gives the same trace. The
independent two-state selector must reproduce explicit projected words.

For A=PL cL+PR cR,At=PR cL+PL cR, fullAC implies Gamma A=At Gamma.
Together with qM=ig(cR M-McL),qMdagger=ig(cL Mdagger-MdaggercR), this gives
the reference operator covariance at external hat momenta0. PhysicalBMHV

must be retained as a negative control, not repaired in the actual action.

Every free numerator contributes one Gamma, every gauge vertex another,
and scalar vertices contribute projectors only. Closed chiral-path parity
requires an even number of scalar insertions. With n<=4 and UVdegree4-n,
the mixed marginal inventory is2Y,2Y+g,2Y+2g,4Y. No coefficient of the last
three is determined by this support argument.
