# Weighted symbol and actual-background applicability

The local reference kernel has entry order t_i+t_j, t_i=2-d_i. Conjugate its
principal symbol by diag(|p|^-t_i) on both sides. This is an order-zero matrix,
not a positive scalar Laplacian. Its inverse has entry order -t_i-t_j. The
45 vector/auxiliary5x5 determinants are -(p^2)^4 and the ghost2x2 determinants
(p^2)^2; scalar principal symbols are p^2. Wick p0=i q0,pj=qj makes p^2=-|q|^2,
so principal invertibility holds away from q=0 independently of both widths.
This is a high-momentum algebraic result,not global Euclidean positivity or
physical zero-mode removal. Constant chart maps preserve the weights.

For local differential K with this background-independent principal symbol,
the formal symbol product is a#b=sum_alpha (1/i)^|alpha|/alpha!
(d_p^alpha a)(d_x^alpha b). The inverse recursion starts with inverse principal
matrix. Each subsequent order depends on finitely many local coefficient jets
and earlier orders. Thus a finite fixed-order Born word has a local coefficient
of momentum degree -4. In four dimensions its radial integral on an explicit
UV shell is logUV times that angular coefficient. This is the conditional
local-symbol argument; it does not establish the actual covariant operator
class from a flat matrix or prove an entire heat/IR/measure construction.

Literature guide: Lesch, On the noncommutative residue for pseudodifferential
operators with log-polyhomogeneous symbols, introduction eqs1.2-1.4,
https://arxiv.org/pdf/dg-ga/9708010 . Its classical residue uses a classical
operator and an auxiliary elliptic positive-leading-symbol heat operator on a
closed smooth manifold. Its residue is obtained from the homogeneous symbol
of degree minus the dimension. These hypotheses must be matched; the mixed
Hessian need not itself be that positive heat operator. We do not import trace
cyclicity, finite regularized trace equality, or global compact-manifold results
as model-specific QAP/IR facts.

Order matters already for the longitudinal inverse: D_mu Delta^-2 D_nu and
D_mu D_nu Delta^-2 coincide for commuting flat derivatives but differ by
D_mu[Delta^-2,D_nu]. Since [Delta^-1,D_nu]=-Delta^-1[Delta,D_nu]Delta^-1,
[Delta^-2,D_nu] contains two ordered inverse products. For local Delta=-D^2,
[Delta,D_nu]=-sum_mu(D_mu F_munu+F_munu D_mu); the extra term has order -4
(after the exterior D_mu), with curvature dimension2. H covariance and the
flat inverse do not select this order. This witness is not a new adopted
reference/scheme. Both ordered local members can have local UV coefficients;
missing order alone must not be misreported as a nonlocality proof.
